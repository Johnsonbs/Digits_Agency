# Digit's Agency — Design System

## Colors

| Name | Hex | Usage |
|---|---|---|
| Cream | `#FFF9EC` | Background |
| Ink | `#2D2A4A` | Text |
| Purple | `#8B7FD6` | Accent |
| Coral | `#FF6B6B` | Math blocks |
| Sky Blue | `#4EA8DE` | Logic blocks |
| Mint Green | `#4ECDC4` | Lookup blocks |
| Sunshine Yellow | `#FFC93C` | Highlights / success |

## Fonts

- **Headings**: rounded, friendly font — "Baloo 2"
- **Body text**: "Nunito"
- Never use a monospace/code font in the visible UI, even though real formulas exist underneath.

## Shape & Spacing

- Rounded corners everywhere: 12–20px radius
- No sharp edges or thin hairline borders
- Generous padding
- Large touch targets: 44px+ minimum (this app is for kids ages 8–13)

## Interaction Rules

- No red error states, ever — wrong actions get a gentle shake and a friendly in-character message instead
- Celebrate success with confetti or a small animation
- Keep everything reversible with an obvious undo
